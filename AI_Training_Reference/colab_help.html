untar_data
Data Sourcing & Directory Management
Downloads and extracts a standard dataset from the fast.ai collection (or any URL) to a local cache directory. Returns a Path object pointing to the extracted folder. If the dataset has already been downloaded, the cached version is used automatically.
untar_data Function
Syntax
untar_data(url, archive=None, data=True, c_key='data', force_download=False)
ParameterTypeDescription
urlURLs / strA URL string or a URLs constant (e.g. URLs.PETS). Specifies the dataset to download.
archivePath | NoneOptional custom archive directory. Defaults to a fast.ai managed cache.
force_downloadboolIf True, re-downloads even if cached. Default is False.
Returns Path
Example Script
from fastai.vision.all import * # Download the Oxford-IIIT Pet dataset path = untar_data(URLs.PETS) # Inspect the returned Path object print(path) # e.g. /root/.fastai/data/oxford-iiit-pet print(path.ls()) # lists contents of the directory # Common URLs constants available in fast.ai # URLs.PETS – Oxford-IIIT Pet dataset (image classification) # URLs.MNIST – MNIST handwritten digits # URLs.IMDB – IMDb movie reviews (text classification) # URLs.ADULT_SAMPLE – Adult census income (tabular) # URLs.ML_SAMPLE – MovieLens ratings (collaborative filtering)
📌 Note
The URLs class contains constants for all standard fast.ai datasets. You can also pass any direct download URL as a string.
See Also get_image_files get_text_files DataBlock
get_image_files
Data Sourcing & Directory Management

ParameterTypeDescription

DataBlock
The DataBlock API
The DataBlock class is the central blueprint for transforming raw data into DataLoaders. It decouples all the decisions about your data — what it is, how to label it, how to split it, and how to augment it — into a single, reusable specification.
DataBlock Class
Constructor Syntax
DataBlock( blocks = (InputBlock, OutputBlock), get_items = get_items_func, get_y = label_func, splitter = splitter_func, item_tfms = [Resize(460)], batch_tfms= aug_transforms(size=224) )
ParameterTypeDescription
blocksTupleA tuple of block types defining input and output data. E.g. (ImageBlock, CategoryBlock) for image classification, (TextBlock, CategoryBlock) for NLP.
get_itemsFunctionA function that receives the path and returns a list of raw items (e.g. get_image_files).
get_yFunctionA labeling function applied to each item to extract its target/label. E.g. parent_label returns the folder name.
splitterFunctionDetermines how to split items into training and validation sets. E.g. RandomSplitter(valid_pct=0.2) or GrandparentSplitter.
item_tfmsListTransformations applied on the CPU to each individual item. Usually used for Resize.
batch_tfmsListTransformations applied on the GPU to full mini-batches. Used for data augmentation via aug_transforms().
ReturnsDataBlock
Example Script – Image Classification
from fastai.vision.all import * path = untar_data(URLs.PETS) # Define a regex function to extract label from filename def label_from_name(fname): return re.search(r'^([^_]+)_\d+\.jpg$', fname.name).group(1) pets = DataBlock( blocks = (ImageBlock, CategoryBlock), get_items = get_image_files, get_y = label_from_name, splitter = RandomSplitter(valid_pct=0.2, seed=42), item_tfms = Resize(460), batch_tfms= aug_transforms(size=224, min_scale=0.75) ) # Create DataLoaders from the DataBlock dls = pets.dataloaders(path/"images", bs=32) dls.show_batch()
💡 item_tfms vs batch_tfms
item_tfms run on the CPU on individual items — use these for resizing to a consistent size before batching. batch_tfms run on the GPU on entire batches — use these for random augmentation. This split is key for performance.
Common Block Types
# Vision (ImageBlock, CategoryBlock) # Single-label classification (ImageBlock, MultiCategoryBlock) # Multi-label classification (ImageBlock, ImageBlock) # Image segmentation / style transfer # NLP (TextBlock.from_folder(...), CategoryBlock) # Tabular TabularDataLoaders.from_csv(...) # more common for tabular

LinearRegression
Classical Machine Learning · Scikit-learn
Implements Ordinary Least Squares (OLS) linear regression. Fits a linear model to minimize the residual sum of squares between observed and predicted values. Used in early course weeks to build intuition before neural networks.
LinearRegression Class
Syntax
from sklearn.linear_model import LinearRegression model = LinearRegression(fit_intercept=True)
ParameterTypeDescription
fit_interceptboolWhether to calculate the intercept. Default True.
Key Methods
# Fit the model model.fit(X_train, y_train) # Predict y_pred = model.predict(X_test) # Evaluate score = model.score(X_test, y_test) # R² score # Inspect coefficients print(model.coef_) # slope(s) print(model.intercept_) # intercept

GridSearchCV
Classical Machine Learning · Scikit-learn
Exhaustive search over a specified parameter grid. Tests every combination of hyperparameter values using cross-validation and selects the best performing configuration. Used in this course for optimising email spam filter models.
GridSearchCV Function / Class
Syntax
from sklearn.model_selection import GridSearchCV gs = GridSearchCV( estimator = model, param_grid = param_dict, cv = 5, scoring = 'accuracy', n_jobs = -1 )
Full Example – Email Spam Filter
from sklearn.model_selection import GridSearchCV from sklearn.svm import SVC from sklearn.pipeline import Pipeline from sklearn.feature_extraction.text import TfidfVectorizer # Build a text classification pipeline pipe = Pipeline([ ('tfidf', TfidfVectorizer()), ('svc', SVC()) ]) # Define the hyperparameter grid param_grid = { 'tfidf__max_features': [1000, 5000], 'svc__C': [0.1, 1, 10], 'svc__kernel': ['linear', 'rbf'] } gs = GridSearchCV(pipe, param_grid, cv=5, scoring='f1', n_jobs=-1) gs.fit(X_train_text, y_train) print("Best params:", gs.best_params_) print("Best F1 score:", gs.best_score_)
⚠️ Colab Warning
GridSearchCV can be slow on Colab's free tier. Set n_jobs=-1 to use all available CPUs, and consider using RandomizedSearchCV for large parameter spaces.
cnn_learner
Model Architectures & Learners
Creates a Learner for image classification and regression tasks using a pretrained convolutional neural network (CNN) as its backbone. The network is automatically adapted for the number of classes in your dataset via a custom head appended to the pretrained body.
cnn_learner Function
Syntax
cnn_learner(dls, arch, metrics=None, pretrained=True, ...)
ParameterTypeDescription
dlsDataLoadersThe DataLoaders object containing training and validation data.
archFunctionThe architecture function. E.g. resnet34, resnet50, vgg16_bn.
metricslistList of metric functions to display during training. E.g. [error_rate, accuracy].
pretrainedboolIf True (default), loads ImageNet pretrained weights. Set False to train from scratch.
ReturnsLearner
Example Script
from fastai.vision.all import * path = untar_data(URLs.PETS) dls = ImageDataLoaders.from_folder(path/"images", valid_pct=0.2, item_tfms=Resize(224)) # Create a ResNet-34 learner learn = cnn_learner(dls, resnet34, metrics=[error_rate, accuracy]) # Common architectures available: # resnet18, resnet34, resnet50 – speed/accuracy tradeoff # vgg16_bn – older but reliable # xresnet50 – fast.ai optimized ResNet # efficientnet_b0 to b7 – via timm integration

text_classifier_learner
Model Architectures & Learners
Creates a Learner for text classification using a pretrained language model. The default architecture is AWD_LSTM. Typically, this follows a two-stage training: first fine-tune a language model, then train the classifier head.
text_classifier_learner Function
Syntax
text_classifier_learner(dls, arch, drop_mult=0.5, metrics=None)
Example Script – IMDb Sentiment
from fastai.text.all import * path = untar_data(URLs.IMDB) # Step 1: Build DataLoaders for language model fine-tuning dls_lm = TextDataLoaders.from_folder(path, is_lm=True) learn_lm = language_model_learner(dls_lm, AWD_LSTM, drop_mult=0.3, metrics=accuracy) learn_lm.fine_tune(1, 2e-2) learn_lm.save_encoder('finetuned') # Step 2: Build classifier DataLoaders dls_cls = TextDataLoaders.from_folder(path, valid='test') learn = text_classifier_learner(dls_cls, AWD_LSTM, drop_mult=0.5, metrics=accuracy) learn.load_encoder('finetuned') learn.fine_tune(4, 1e-2)

learn.fine_tune
The Training Loop
The primary method for transfer learning. First freezes the pretrained body and trains only the newly added head for one epoch, then unfreezes all layers and trains the full network for the specified number of epochs using discriminative learning rates.
learn.fine_tune Method
Syntax
learn.fine_tune(epochs, base_lr=2e-3, freeze_epochs=1)
ParameterTypeDescription
epochsintNumber of epochs to train after the freeze phase (full network).
base_lrfloat | sliceLearning rate. Use slice(lr_min, lr_max) for discriminative learning rates across layer groups.
freeze_epochsintNumber of epochs to train with the body frozen (head only). Default is 1.
Example Script
from fastai.vision.all import * path = untar_data(URLs.PETS) dls = ImageDataLoaders.from_folder(path/"images", item_tfms=Resize(224)) learn = cnn_learner(dls, resnet34, metrics=error_rate) # Find the optimal learning rate first learn.lr_find() # Fine-tune: 1 epoch frozen → 4 epochs unfrozen learn.fine_tune(4, base_lr=3e-3) # Optional: use discriminative learning rates learn.fine_tune(4, base_lr=slice(1e-5, 1e-3))
📌 When to use fine_tune vs fit_one_cycle
Use fine_tune when you have a pretrained model and want to adapt it to new data. Use fit_one_cycle when training from scratch (tabular, collab) or when you've manually managed freezing with learn.freeze() / learn.unfreeze().
See Also learn.fit_one_cycle cnn_learner learn.export
learn.fit_one_cycle
The Training Loop
Implements the 1-cycle learning rate policy, which gradually increases the learning rate then decreases it over training epochs. Produces better results in fewer epochs compared to a fixed learning rate.
learn.fit_one_cycle Method
Syntax
learn.fit_one_cycle(n_epoch, lr_max=None, div=25.0)
Example Script – Tabular from Scratch
# After creating tabular_learner... learn.fit_one_cycle(5, 1e-3) # Typical training output columns: # epoch | train_loss | valid_loss | accuracy | time # Show training curve learn.recorder.plot_loss()
Manual SGD Loop
The Training Loop
The low-level training loop using Stochastic Gradient Descent. Understanding this loop builds intuition for how all deep learning frameworks work under the hood. Covered in advanced units.
SGD Training Loop Pattern
The Three Core Operations
# loss.backward() — compute gradients via backpropagation # opt.step() — update parameters using gradients # opt.zero_grad() — reset gradients to zero for next batch
Full Manual Training Loop
import torch import torch.nn as nn # Simple 2-layer network model = nn.Sequential( nn.Linear(10, 32), nn.ReLU(), nn.Linear(32, 1) ) opt = torch.optim.SGD(model.parameters(), lr=0.01) loss_fn = nn.MSELoss() for epoch in range(100): for X_batch, y_batch in dataloader: # 1. Forward pass y_pred = model(X_batch) loss = loss_fn(y_pred.squeeze(), y_batch) # 2. Backward pass — compute gradients loss.backward() # 3. Update weights opt.step() # 4. Reset gradients BEFORE next batch opt.zero_grad() print(f"Epoch {epoch+1}: loss = {loss.item():.4f}")
⚠️ Common Mistake
Always call opt.zero_grad(). If you forget, gradients accumulate across batches and your model will not train correctly.

load_learner
Inference & Model Export
Reloads a previously exported Learner from a .pkl file for use in production or deployment environments. The loaded learner is immediately ready for inference without any retraining.
load_learner Function
Syntax
load_learner(fname, cpu=True)
Example – Full Inference Pipeline
from fastai.vision.all import * # Load the exported model learn_inf = load_learner('my_model.pkl') # Run prediction on a new image img = PILImage.create('new_cat.jpg') pred, idx, probs = learn_inf.predict(img) print(f"Predicted: {pred} ({probs.max():.1%} confident)")
📌 Deployment Note
Set cpu=True when loading in environments without a GPU (e.g. HuggingFace Spaces, Render). For Voilà apps, always load the learner outside the widget callback to avoid reloading on every button press.

# Step 3 (next cell): Apply the changes from the GUI for idx in cleaner.delete(): cleaner.fns[idx].unlink() # Delete the file for idx, cat in cleaner.change(): shutil.move(str(cleaner.fns[idx]), path/'train'/cat) # Move to correct folder # Step 4: Retrain on the cleaned dataset learn.fine_tune(3)

interp.plot_top_losses

interp.most_confused
Interactive Data Cleaning
Returns the pairs of classes that the model most frequently confuses, sorted by frequency. Also accessible visually via interp.plot_confusion_matrix().
interp.most_confused Method
Syntax
interp.most_confused(min_val=1)
Example Script
from fastai.vision.all import * interp = ClassificationInterpretation.from_learner(learn) # Returns list of (actual, predicted, count) tuples confused = interp.most_confused(min_val=5) print(confused) # e.g. [('american_pit_bull_terrier', 'staffordshire_bull_terrier', 12), ...] # Plot full confusion matrix interp.plot_confusion_matrix(figsize=(12,12), dpi=60)
💡 Interpretation Tip
High confusion between two classes usually means the classes are visually similar (a genuine classification challenge), there is label noise in your dataset, or you need more training data for those specific classes. Use plot_top_losses to inspect individual cases.
